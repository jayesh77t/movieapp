# movieapp
🎬 Flutter Movie Streaming App
A sleek and modern movie streaming app built with Flutter, powered by Appwrite.io for backend services including database, authentication, storage, and real-time updates. Appwrite also functions as the admin panel to manage movies, users, and content dynamically.

🚀 Features
📽️ Browse and stream movies
🗂️ Categories & genre filtering
🔍 Movie search functionality
💾 Appwrite Database integration
📤 Admin panel via Appwrite Console
📱 Responsive UI for Android & iOS
⚡ Fast performance with clean UI
